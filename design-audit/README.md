# UzIntellekt — UI/UX аудит и план унификации

Скоуп: два фронтенда в монорепо.

| Приложение | Назначение | Порт (dev) | Стек |
|---|---|---|---|
| `uz-intellekt` | Публичный сайт (маркетинг + новости + контакты + OneID-вход) | 5173 | React 19, RR7, Tailwind 3, shadcn-style |
| `dashboard` | Личный кабинет автора (асарлар, договоры, профиль) | 3002 | React 18, RR6, Tailwind 3, shadcn-style |

## Главное наблюдение
Дизайн-токены (`index.css` CSS-переменные + `tailwind.config.js`) у обоих проектов **идентичны** — общая палитра, радиусы, тени, шрифт Inter. То есть фундамент общий. Расхождения — в **применении**: бренд (логотип), герои, локализация статусов, состояния (пусто/загрузка/ошибка), мелочи.

## Файлы аудита
- `findings.md` — все находки (баги + UI/UX), сгруппированы по severity.
- `todo.md` — мастер-чеклист: каждая страница и каждый shared/ui компонент со статусом проверки.
- `design-system.md` — целевые решения по унификации (бренд, герои, статусы, состояния).

## Статус
Первичный проход выполнен (визуальный обход всех публичных страниц uz-intellekt и всех страниц dashboard в залогиненном состоянии + сверка с кодом). Детальная попиксельная проверка каждого элемента ведётся итеративно — см. `todo.md`.

## Правило работы
Редизайн — только после согласования. Перед изменением каждой заметной страницы показывается preview в Chrome.
