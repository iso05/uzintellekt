# Целевая дизайн-система (предложение к согласованию)

Опирается на уже общие токены обоих проектов. Цель — один узнаваемый бренд для гос-платформы интеллектуальной собственности: спокойный, доверительный, «государственно-цифровой».

## Бренд
- **Один логотип** для обоих приложений. Сейчас рассинхрон: синий щит (сайт) vs фиолетовый квадрат (кабинет). Предложение: единый знак на основе синего (`--primary 217 76% 42%`) щита + копирайт-метка ©. dashboard переходит на него.
- Wordmark: «UzIntellekt» Inter 700; в кабинете под ним строка «Intellektual mulk» — оставить.

## Палитра (без изменений токенов)
- primary (синий) — основной акцент/CTA.
- accent (тёплый янтарный `38 92% 50%`) — точечно (бейджи «скоро», маркеры шагов), не как заливка.
- success/warning/destructive — только для статусов.
- Фон страниц `--background` (почти белый, лёгкий холодный), карточки белые.

## Типографика
- Inter уже подключён. Шкала: Display (hero) 700/800, H2 секций 700, body 400/500, captions/eyebrows 600 uppercase tracking-wide.
- Эйбрау-метки (eyebrow) — единый компонент: маленький pill `primary-soft`.

## Герои (унификация U1)
- Главная: светлый hero с иллюстрацией справа (как сейчас).
- Внутренние страницы: единый светлый паттерн «eyebrow + H1 + лид», без сплошной синей заливки. Services-hero перевести в общий паттерн (или, по согласованию, наоборот — синий full-bleed для всех внутренних).

## Карточки
- Единый стиль: `rounded-xl`, `shadow-soft`, бордер `border`, hover → `shadow-soft-md` + лёгкий подъём. Применить к service-cards, news-cards, dashboard stat-cards.

## Статусы (унификация + B1)
- Единая карта статус→{label, variant} в каждом приложении; **никогда** не показывать сырой enum (добавить `CREATED` и default-fallback на «Noma'lum» уже есть).
- Бейдж статуса: точка `bg-current` + локализованный текст (как в `ContractStatusBadge`).

## Состояния
- Список: всегда через общие `loading-state` (skeleton) / `empty-state` (иконка + заголовок + CTA) / inline-error.
- Тосты: `sonner`, одинаковая позиция (top-right) и стиль в обоих.

## Качество (floor)
- Адаптив до 375px, видимый `focus-visible` ring (`--ring`), `prefers-reduced-motion`, alt у иллюстраций, контраст плейсхолдеров ≥ AA.

## Локализация
- Все строки — через i18n (uz/ru/en). Никаких хардкод-дат: формат даты через `Intl.DateTimeFormat(locale)`.
