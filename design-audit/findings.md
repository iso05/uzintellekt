# Проход унификации 2026-06-25 (попиксельный обзор всех экранов через Chrome)

**Метод:** скриншоты всех страниц/диалогов/кнопок обоих приложений на десктопе (~1200px) + сверка классов Tailwind в исходниках. Кабинет — на реальных данных (JWT).

**Фундамент УЖЕ унифицирован (не трогаем):** все примитивы `shared/ui` (button, badge, card, dialog, input, select, tabs, table, page-header …) **побайтово идентичны** в обоих проектах; токены `:root` (`--primary 221 83% 53%`, `--accent 16 96% 61%`, `--radius .625rem`, тени) совпадают. Единственное намеренное различие — сайт даёт `h1–h3` сериф Spectral, кабинет — Inter (по брифу). Диалоги кабинета (PdfPreviewModal, AddressEditDialog, CancelWork alert) корректно используют shared `Dialog`/`AlertDialog`.
