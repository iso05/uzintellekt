### Phase 3 — Грид-паритет: Пользователи & Модерация-список ✅
**Outcome:** Пользователи и очередь модерации получают тот же тулбар (`DataGridToolbar` + `useGridQuery` + `SortableTableHead`).
- [x] **Эмпирически прозондировал API** (реальный grid через браузер): `lk` (contains, регистронезависимо) поддержан на `lastName`/`firstName`/`pinfl` и `name` (works); `phone`/`phones`/`fullName` → 500. Фильтры ANDятся (OR нет). Сортировка: users `lastName`/`createdAt` ✓ (`fullName`→500), works `name`/`createdAt` ✓. Range-операторов для дат нет.

- [x] Модерация-список: поиск по названию (`name lk`, мин. 2 симв.) (M3, частично — см. ниже); сортировка Номи (`name`) + Яратилган (`createdAt`) (M4). Статус-селект перенесён в тулбар.

- [x] i18n: `user.search_ph` обновлён, `moderation.search_ph` добавлен (4 локали).
